# Random practice: AI development and deadlines

## Context

- Scenario: 同事關心最近增加的工作量，討論 PM 的時程期待、AI 開發與人工驗證。
- Learner role: 說明開發時程與 AI 使用限制的同事
- Coach role: 關心工作近況的同事
- Practice focus: 描述不合理的期限、說明需要更多時間，以及區分 AI 寫程式與人工 review/testing。
- Completion: 學習者以「請結束對話」明確要求結束；三次英文回覆後儲存。
- Privacy: 未記錄公司名稱、實際產品、程式碼、私人網址或客戶資料；角色對話不視為已核實的個人背景。
- Timing: 完成日期已知；開始與結束的精確時間未記錄，對應欄位保留 null。

## Dialogue

### Coach opening

Hey, you’ve had a pretty busy week. How are you holding up?

### Turn 1

#### Learner — original

```text
yeah, even you know what I am stuggling with. The requirement from our product manager has been set the dead line which is not achieved as possible.
so I need to spend more to develop it.
```

#### Coaching

- Classification: 錯誤（spelling、期限句子的結構、spend 缺少 time）；不自然（even you know，視原意而定）。
- Grammar revision: Yeah, even you know what I am struggling with. Our product manager has set a deadline that is impossible to meet, so I need to spend more time developing it.
- Natural revision: Yeah, you know what I’m dealing with. Our PM has set an unrealistic deadline, so I need more time to finish the work.
- 中文說明: 原意若為「你也知道我的狀況」，自然版本使用 you know what I’m dealing with；保留 PM 的期限不切實際、開發需要更多時間的主要意思。對話中未解釋文法規則。
- Evidence: 能提出時程問題及需要更多時間的原因；本回合沒有獨立使用既有 feel-burned-out 複習目標或可評估的對應表達，不判為複習失敗。

#### Coach — English reply

That sounds stressful. Have you talked to the PM about how much more time you need?

### Turn 2

#### Learner — original

```text
Yes, I did, but I think he is in the fantasitc world that AI can do everything he want, so that he think why can't we use AI to facilitate our work.
```

#### Coaching

- Classification: 錯誤（fantasitc、he want、he think、句子結構）；語氣調整（living in a fantasy world 語氣較強）。
- Grammar revision: Yes, I did, but I think he’s living in a fantasy world where AI can do everything he wants, so he thinks, “Why can’t we use AI to facilitate our work?”
- Natural revision: Yes, I did, but he seems to think AI can do everything, so he doesn’t understand why we can’t use it to speed up the work.
- 中文說明: living in a fantasy world 語氣較強；he seems to think 的版本比較適合職場討論。facilitate our work 本身可理解且適合較正式語域，speed up the work 是此情境較口語的選擇。
- Evidence: 能說明 PM 的期待並以 AI can do everything 與 facilitate our work 表達觀點；自然版本的措辭由教練提供，未視為獨立掌握。

#### Coach — English reply

I see. Which parts of the work can AI actually help with, and which parts still need your time and judgment?

### Turn 3

#### Learner — original

```text
In my opinion, I most of coding work can be delegated to AI agent, but for code review, test if the result from AI implementation is correct or not. those task still be done by human.
```

#### Coaching

- Classification: 錯誤（I most of coding work、名詞單複數、被動句子結構）；不自然（code review/testing 的句子銜接）。
- Grammar revision: In my opinion, most coding work can be delegated to AI agents, but code review and testing whether the AI-generated code works correctly still need to be done by humans.
- Natural revision: I think AI can handle most of the coding, but we still need people to review and test what it produces.
- 中文說明: 自然版本保留「多數寫程式工作可交給 AI，但人仍需 review 與測試」的主張；未展開文法規則說明。
- Evidence: 自行使用 In my opinion、can be delegated to、code review 與 AI implementation 表達工作分工，並能用 but 對比 AI 能做的工作與人工驗證。

#### Coach — English reply

That makes sense. Writing the code is only part of the job. What kinds of problems have you caught when reviewing AI-generated code?

## Session summary

### Strengths

- 三次回覆能連貫說明時程問題、PM 對 AI 的期待，以及人工 review/testing 的必要性。
- 自行使用 In my opinion、can be delegated to、code review、facilitate our work 等觀點與工作用語。
- 能以 but 與 so 連結對比與原因結果，主要意思可理解。

### High-value corrections

- The requirement ... has been set the dead line ... → Our product manager has set an unrealistic deadline.
- spend more to develop it → spend more time developing it / need more time to finish the work.
- he want / he think → he wants / he thinks.
- those task still be done by human → those tasks still need to be done by humans.
- stuggling → struggling; dead line → deadline; fantasitc world → fantasy world（此處要表達不切實際的想像）。

### Useful expressions

- set an unrealistic deadline: 設定不切實際的期限；由教練提供。
- need more time to finish the work: 需要更多時間完成工作；由教練提供。
- speed up the work: 加快工作進度；由教練提供，未觀察獨立使用。
- delegate work to AI agents: 將工作交給 AI agents；學習者自行使用 can be delegated to，名詞形式仍需修正。
- review and test what it produces: 審查並測試 AI 產出的內容；由教練提供。

### Next practice target

- 用兩到三句向 PM 說明 AI 可以協助的部分、人工驗證需要的時間與合理的交付期限。
- 優先練習 set a deadline、spend more time doing something，以及仍需人工完成的表達。
