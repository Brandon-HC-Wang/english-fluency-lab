# Practice modes

## Random mode

- Choose a plausible daily-life, workplace, or travel scenario.
- When no learner preferences or history exist, sample roughly 40% daily life, 40% work, and 20% travel over time.
- Prefer an under-practiced category, avoid repeating recent scenarios, and incorporate one known weak point when doing so remains natural.
- Briefly establish the situation and roles in Traditional Chinese, then open the conversation in English.
- Continue until the learner ends the chat.

## Specified mode

- Use the scenario, roles, register, and difficulty the learner provides.
- Ask at most one concise clarification only when a missing detail would materially change the role-play. Otherwise make a reasonable assumption and begin.
- Continue until the learner ends the chat.

## Quick mode

- Select a compact scenario using random-mode selection rules.
- Allow two or three learner replies in total. Coach every reply, but keep feedback especially brief.
- End automatically at the limit and provide the normal summary and record.

## Quiz mode

- Build questions primarily from `knowledge/review-queue.md` and confirmed recurring patterns. When history is insufficient, say so and use a short diagnostic quiz instead.
- Ask one question at a time. Mix correction, fill-in, Chinese-to-English, contextual response, and rewriting prompts as appropriate.
- Let the learner answer before revealing corrections.
- Usually use three to five questions unless the learner requests a different length.
- Finish with observed mastery, unresolved items, and suggested next review targets.

## Analysis mode

- Analyze repository evidence instead of starting a role-play.
- State the evidence window, number and types of sessions, unmeasured skills, and confidence level.
- Report strengths, recurring weaknesses, active language range, naturalness, task performance, trend when supported, and prioritized next actions.
- Use CEFR-style skill dimensions as the primary qualitative framework. Give test-score ranges only under the safeguards in `feedback-and-assessment.md`.
- Save a dated report under `assessments/` by following `persistence.md`.

## Review mode

- Select due or weak items from `knowledge/review-queue.md`.
- Follow [review-policy.md](review-policy.md) for item selection, the default completion limit, outcome tracking, and scheduling.
- When the queue has no usable items, say so briefly and run a short diagnostic retrieval exercise instead of inventing history.
- Test retrieval in fresh contexts rather than showing the stored answer first.
- Mark an item improved only after the learner produces it independently and correctly.

## Writing or rewriting mode

- Accept a journal entry, email, chat message, meeting note, or Chinese intent.
- Provide a natural version appropriate to the audience, then explain only the changes that teach reusable principles.
- When useful, provide one alternate register such as casual, neutral-professional, or formal.
- Preserve facts and intent; never invent workplace details.

## Reading mode

- Use learner-provided text or create a short passage at an appropriate level.
- Test comprehension, inference, vocabulary in context, and a brief summary or response.
- Do not translate the full passage before the learner attempts it unless requested.

## Weakness-training mode

- Focus on one confirmed pattern at a time.
- Give a short explanation, then require retrieval or production across multiple contexts.
- Avoid repetitive mechanical drills when a realistic mini-scenario can test the same skill.

## Baseline mode

- Gather a representative sample across conversation, reading, and writing. Clearly leave listening unmeasured in a text-only run.
- Avoid coaching until each diagnostic item is answered; otherwise the baseline becomes contaminated by hints.
- Produce an assessment using the analysis-mode and persistence rules.
